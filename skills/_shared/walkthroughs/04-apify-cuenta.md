# Apify Account / Cuenta Apify

**EN:** Apify is a service that lets you scrape websites that use JavaScript (like Twitter/X, LinkedIn, or any site that loads content dynamically). Regular fetch requests can't access these sites — Apify runs a full browser in the cloud to do it.

**ES:** Apify es un servicio que te permite scrapear sitios web que usan JavaScript (como Twitter/X, LinkedIn, o cualquier sitio que carga contenido dinámicamente). Las solicitudes normales no pueden acceder a estos sitios — Apify corre un browser completo en la nube para hacerlo.

---

## Do you need Apify? / ¿Necesitas Apify?

**You need it if your source is:** Twitter/X, LinkedIn, Instagram, TikTok, or any site that shows a blank page if you disable JavaScript in your browser.

**You don't need it if:** you're using RSS feeds, regular news sites, or APIs.

**ES:** Lo necesitas si tu fuente es: Twitter/X, LinkedIn, Instagram, TikTok, o cualquier sitio que muestra una página en blanco si deshabilitas JavaScript en tu browser. No lo necesitas si usas RSS feeds, sitios de noticias normales, o APIs.

---

## Step 1 — Create account / Crear cuenta

1. Go to / Ve a https://apify.com
2. Click **Sign up for free**
3. Sign up with email or Google

---

## Step 2 — Get your API key / Obtener tu llave de acceso

1. Go to / Ve a https://console.apify.com/account/integrations
2. Copy your **Personal API token**
3. Paste it in the chat when asked

**ES:** Ve a https://console.apify.com/account/integrations, copia tu **Personal API token**, pégalo en el chat cuando te lo pida.

---

## Cost / Costo

The free tier includes **$5 of compute credits per month**. For one daily scrape of Twitter/LinkedIn, this is usually enough and you won't exceed it.

El plan gratuito incluye **$5 de créditos de cómputo por mes**. Para un scrape diario de Twitter/LinkedIn, esto generalmente alcanza y no lo superarás.

**Typical cost for 1 daily scrape: ~$0.10–0.50/month** ✅
